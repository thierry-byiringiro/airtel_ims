# 📦 Airtel Inventory Management System (IMS)

## 📌 Project Description
The Airtel Inventory Management System (IMS) is a Spring Boot-based web application designed to manage end-user equipment such as laptops, desktops, and mobile phones.

The system helps administrators:
- Register and manage assets
- Assign assets to employees
- Track asset status (Available, In Use, Damaged)
- Manage employees
- Handle asset return processes
- Maintain assignment history

## ⚙️ Setup Instructions

### 1. Prerequisites
Make sure you have installed:
- Java 8+
- Maven
- MySQL Server
- Eclipse or IntelliJ IDEA

### 2. Database Setup

Create the database:
CREATE DATABASE airtel_ims;

After creating the database open phpmyadming and then go to your new created database click on the import menu and then click browse file and 
add the .sql file inside the zipped file of the project
